HF76-PUBLISH2 – Projektweiter Duplicate-Button-Audit

Ziel: In einer sichtbaren Aktionsgruppe darf keine unterschiedliche Aktion dasselbe Buttonbild verwenden. Echte identische Ziel-/Aktionsduplikate werden entfernt; fachlich unterschiedliche Aktionen erhalten eindeutige zentrale Registry-Typen.

Bereinigte Bereiche:
- Enterprise Dashboard
- Dashboard Fehleraktionen
- Recovery Administration
- Setup/Systemprüfung
- Projektverwaltung
- Security Audit Navigation
- DataForm Records Header
- DataForm Import Detailaktionen
- DataForm Package Alle/Keine
- Report Exportformate
