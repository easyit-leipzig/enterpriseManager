# Hotfix HF68 – Enterprise-Manager-Logo und linksbündiges DataForm-Branding

## Änderungen
- Das bereits vorhandene Enterprise-Manager-Logo `assets/img/easyit-epManager-logo.png` wird zentral in der globalen Enterprise-Topbar verwendet.
- Ist die PNG-Datei in einer Installation nicht vorhanden, bleibt der bisherige `eI / easyIT Enterprise`-Header als Fallback erhalten.
- Das Enterprise-Manager-Logo wird auch in der DataForm-Runtime-Topbar verwendet.
- Das easyIT-DataForm-Logo wird auf DataForm-Seiten linksbündig statt zentriert dargestellt.
- Projekt- und DataForm-Branding bleiben klar getrennt: Enterprise Manager oben in der globalen Navigation, DataForm im eigenen weißen Branding-Bereich.

## Asset
Die Integration verwendet bewusst die bereits vorhandene Datei:

`assets/img/easyit-epManager-logo.png`

Die Datei wird durch HF68 nicht ersetzt.
