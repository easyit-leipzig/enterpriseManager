# RC1.8 Phase 6.8 – Final-Candidate-Konsolidierung

Phase 6.8 friert den Funktionsumfang ein. `RELEASE_CANDIDATE` kennzeichnet den Stand als `RC1.8-FC1`, während `VERSION` aus Kompatibilitätsgründen die interne Phase-Serie fortführt. Neue Features sind ab diesem Stand bis zur Freigabe ausgeschlossen.
