# Roadmap von 1.0.0-rc.1 zu 1.0.0

## RC-Stabilisierung

- reale Installation in Development und Production
- Upgrade von build0043 auf build0044
- Backup/Restore-Abnahme
- Security- und Production-Gate-Abnahme
- API- und Abwärtskompatibilitätsprüfung

## Freigabe 1.0.0

Nach bestandener Stabilisierung wird nur die Versionskennung auf `1.0.0` angehoben. Neue Funktionen beginnen danach in `1.1.0`; Breaking Changes frühestens in `2.0.0`.
