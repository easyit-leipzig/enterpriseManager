# DataForm5-Core 1.0.0 – Final Release

`DataForm5-Core 1.0.0` ist der erste stabile, produktneutrale Core der easyIT-Enterprise-Plattform.

## Freigabestatus

- Kanal: Stable
- Version: 1.0.0
- Build: build0045
- API-Status: stabil
- Feature Freeze des 1.x-Kerns: aktiv
- Rückwärtskompatibilität innerhalb 1.x: verbindlich

## Zulässige Änderungen in 1.x

- Fehlerkorrekturen,
- Sicherheitskorrekturen,
- Performanceverbesserungen,
- Dokumentationskorrekturen,
- rückwärtskompatible Erweiterungen bestehender Verträge.

Breaking Changes und neue grundlegende Core-Layer erfordern eine neue Major-Version.
