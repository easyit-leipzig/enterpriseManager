# LTS- und Wartungsrichtlinie

Für `DataForm5-Core 1.0.0` gilt:

1. Sicherheits- und Datenintegritätsfehler haben höchste Priorität.
2. Öffentliche Interfaces und Konfigurationsschlüssel bleiben innerhalb der Hauptversion 1 rückwärtskompatibel.
3. Abgekündigte APIs werden vor einer Entfernung dokumentiert und mit Ersatzpfad versehen.
4. Jede Aktualisierung benötigt Recovery-Punkt, Kompatibilitätsprüfung, Qualitäts-Gate und Release-Manifest.
5. Produktlogik wird nicht in den Core aufgenommen.
