# DataForm5-Core build0044

## Phase 44 – Release Candidate, Stabilisierung und Core-Abschlussprüfung

Dieser Build markiert `1.0.0-rc.1`. Ab diesem Stand gilt ein Feature Freeze für den Core. Zulässig sind nur noch Fehlerkorrekturen, Sicherheitskorrekturen, Dokumentationsverbesserungen und nachweislich rückwärtskompatible Stabilisierung.

## Abnahmekriterien

- feste RC-Version und Buildkennung
- vorhandene Kern-, Konfigurations-, Test- und Storage-Struktur
- vollständige Pflichtdokumentation
- beschreibbares Storage-Verzeichnis
- PHP 8.1 oder neuer
- maschinenlesbarer RC-Bericht
- vollständige Syntax-, Regressions- und Archivprüfung
